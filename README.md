# VPN Bot Lite

Свой VPN-сервер за 10 минут, которым полностью управляют из Telegram-бота. Сделан под блокировки в России: сервер выглядит как обычный сайт, а при блокировке IP устройства перенастраивать не нужно.

- **Протоколы:** VLESS Reality и VLESS XHTTP для телефонов и ПК, AmneziaWG 2.0 для роутеров.
- **Маскировка:** VPN спрятан внутри «обычного сайта» на вашем домене с настоящим сертификатом Let's Encrypt.
- **Устойчивость к блокировкам:** бесплатный домен DuckDNS вместо IP и сторож, который следит за доступностью из России.
- **Просто:** один контейнер (+ Caddy для сертификата), ~2 500 строк Python, 1 ГБ RAM хватает. Обновления — кнопкой в боте, готовый образ с GitHub за минуту.

Что нового — в [CHANGELOG.md](CHANGELOG.md).

## Возможности

- **Пользователи**: добавить (можно пачкой), включить/отключить, удалить (по одному или всех разом — с подтверждением и автоматическим бэкапом), срок действия, лимит трафика, сброс трафика. У каждого — тип доступа: 🔗 VLESS, 📡 AmneziaWG или оба; список по страницам и с фильтром по типу, лишние ключи не выдаются. Перенесённые через `import-awg` клиенты сразу помечаются как AmneziaWG. Автоотключение по сроку или лимиту с уведомлением админу.
- **Подписки**: одна https-ссылка на пользователя для Happ, v2RayTun, Hiddify, v2rayN, Streisand — приложение само подтягивает ключи, трафик и дату окончания. QR-код в боте и веб-страница с инструкцией.
- **AmneziaWG для роутеров** (Keenetic/Netcraze, OpenWrt) и для телефонов: готовый `.conf` и QR из бота. Новые конфиги устройств маскируются под QUIC (HTTP/3).
- **Максимальная маскировка** (`./vpn.sh stealth`): VLESS на стандартных портах 443/8443, SNI — ваш домен, а всем, кто не является клиентом (DPI-проверки, браузеры), сервер показывает обычный сайт.
- **Защита от блокировки IP**: домен DuckDNS (бот сам обновляет его при смене IP) и сторож — раз в час проверяет доступность из России и пишет, если что-то не так.
- **Статистика**: трафик пользователей, CPU/RAM/диск, состояние ядер. **Логи** ядер прямо в боте.
- **Кто в сети**: 🟢 / ⚪️ у каждого пользователя, «Сейчас онлайн: N из M», фильтр онлайн; в карточке — сколько онлайн, через что и когда был в последний раз.
- **Обновления**: Xray и Hysteria2 — кнопкой с проверкой и откатом; сам бот — кнопкой или `./vpn.sh update`, перед обновлением видно, что изменится; если что-то не так — «↩️ Вернуть бота на …» или `./vpn.sh rollback`. По желанию — ночное автообновление (выключено по умолчанию).
- **Бэкап**: файл базы по кнопке «💾 Бэкап»; восстановление — отправить файл боту.
- **Диск**: при заполнении на 80% бот предупреждает и сам чистит лишнее (старые образы Docker, системный журнал, кэш apt, старые логи); вручную — **📊 Сервер → 🧹 Очистить диск** или `./vpn.sh cleanup`. Сам бот в `/var/log` не пишет, его логи ограничены по размеру.
- **Сводка за неделю**: по понедельникам в 10:00 (МСК) бот присылает итоги: состояние сервера (перерывы в работе, CPU, RAM, диск), доступность из России по ежечасным проверкам, трафик за неделю, самые активные пользователи, кто не пользовался, у кого кончается срок. В любой момент — **📊 Сервер → 📋 Сводка за неделю**.
- **Надёжность**: упавшее ядро перезапускается само; BBR и UDP-буферы настраиваются при установке. `./vpn.sh doctor` собирает всю диагностику одним выводом без секретов.
- Hysteria2 есть, но выключена по умолчанию: UDP у многих российских провайдеров режется. Отдельного прокси для Telegram нет — Telegram работает через VPN.

## Установка

Нужно:
- **VPS за рубежом** (Нидерланды, Германия и т.п.) с Ubuntu 22.04/24.04 или Debian 12, 1 ГБ RAM хватает, root-доступ;
- **бот** — создайте у [@BotFather](https://t.me/BotFather) и скопируйте токен;
- **ваш Telegram ID** — узнать у [@userinfobot](https://t.me/userinfobot);
- **бесплатный домен DuckDNS** — войдите на [duckdns.org](https://www.duckdns.org) через GitHub или Google, впишите имя (например, `ivan-vpn`) → **add domain**, скопируйте **token** (не показывайте его никому; сменить: меню `|||` → recreate token).

### 1. Установить бота
```bash
apt-get update && apt-get install -y git
git clone https://github.com/ProffeSOr24/vpnbot_lite.git /opt/vpnbot-lite
cd /opt/vpnbot-lite
./vpn.sh install <ТОКЕН_БОТА> <ВАШ_TELEGRAM_ID>
```
Скрипт поставит Docker, настроит ядро, скачает готовый образ и запустит бота. Через минуту бот пришлёт «запущен».

### 2. Свой домен и https
```bash
./vpn.sh ddns <ИМЯ> <ТОКЕН_DUCKDNS>     # имя без .duckdns.org
```
Бот будет держать `ИМЯ.duckdns.org` на IP сервера, подписки станут `https://ИМЯ.duckdns.org:2443/…` с сертификатом Let's Encrypt. Нужен свободный порт 80.

### 3. Маскировка под сайт
```bash
./vpn.sh stealth
```
VLESS — на 443 и 8443, SNI = ваш домен, посторонним — сайт-приманка. Проверка: откройте `https://ИМЯ.duckdns.org` в браузере — должна быть страница «Заметки» с замочком.

### 4. Пользователи и устройства
В боте: `/menu` → **👥 Пользователи** → **➕ Добавить** → имя (например, `ivan` или `ivan 30 100` — 30 дней, 100 ГБ). Дальше в карточке пользователя:
- **🔗 Ключи и QR** — ссылка-подписка для телефона/ПК: в **Happ** «+» → «Вставить из буфера», выбрать **XHTTP** и подключиться;
- **📡 AWG приложение** — `.conf` и QR для AmneziaVPN/AmneziaWG на телефоне или ПК;
- **📶 AWG роутер** — `.conf` для Keenetic/Netcraze или OpenWrt (см. ниже).

Если у хостера свой фаервол, откройте: 80, 443, 8443, 2443 (TCP) и 51820 (UDP).

### Порты

| Порт | Что |
|---|---|
| 443/tcp | VLESS Reality (с `stealth` — ещё и сайт-приманка) |
| 8443/tcp | VLESS XHTTP |
| 80/tcp | Let's Encrypt и переадресация на сайт |
| 2443/tcp | ссылки-подписки (https) |
| 51820/udp | AmneziaWG |

Меняются в `.env`, затем `./vpn.sh restart`.

### Подписки по https без своего домена

Happ и некоторые другие приложения не принимают подписку по `http://`. Домен покупать не нужно:

```bash
./vpn.sh https        # подписки на https://<IP-через-дефисы>.nip.io:2443
./vpn.sh https 443    # или на стандартном порту, если 443/tcp свободен

# если на сервере уже есть сертификат (например, от mercurykd/vpnbot) — без Caddy и порта 80:
./vpn.sh https-cert /root/vpnbot/certs/cert_public /root/vpnbot/certs/cert_private
```

Скрипт возьмёт бесплатное имя вида `203-0-113-10.nip.io` (оно всегда указывает на ваш IP) и запустит Caddy, который сам получает и продлевает сертификат Let's Encrypt. Для проверки Let's Encrypt нужен свободный порт **80**. После этого ссылки в боте станут `https://…`.

## Как пользоваться

`/menu` → **👥 Пользователи** → **➕ Добавить** → отправьте имя, например `ivan`, или `ivan 30 100` (30 дней, 100 ГБ). Можно несколько строк сразу.

В карточке пользователя → **🔗 Ключи и QR** — бот пришлёт QR-код и ссылку-подписку. Её нужно отправить человеку:

- **Android / iOS**: Hiddify, v2RayTun, Happ — «Добавить из буфера» или сканировать QR.
- **Windows**: Hiddify или v2rayN — «Добавить подписку».
- **macOS**: Hiddify, Streisand.

### AmneziaWG на роутер

Карточка пользователя → **📶 AWG роутер** — бот пришлёт файл `имя-router.conf`. Лучше завести отдельного пользователя на каждый роутер.

- **Keenetic / Netcraze** (KeeneticOS 4.2+): «Интернет» → «Другие подключения» → «WireGuard» → «Загрузить из файла» → выбрать `.conf`. Затем включить подключение и в «Приоритетах подключений» назначить его нужным устройствам или сделать основным.
- **OpenWrt**: установите `kmod-amneziawg`, `amneziawg-tools`, `luci-proto-amneziawg` (пакеты из [amneziawg-openwrt](https://github.com/amnezia-vpn/amneziawg-openwrt/releases) под вашу версию), затем «Network → Interfaces → Add new interface → AmneziaWG» → «Load configuration» и вставьте содержимое `.conf`.
- **Телефон / ПК**: карточка → **📡 AWG приложение** → в AmneziaVPN или AmneziaWG импорт файла или QR.

Сервер принимает AmneziaWG 1.0 и 2.0. Конфиги для приложений начинают подключение пакетом, похожим на QUIC (HTTP/3) — это усиленная маскировка; если старое приложение такой конфиг не принимает — **⚙️ Настройки → Маскировка новых AWG-конфигов: как у сервера**. В конфиге для роутера строк I1–I5 нет: прошивки Keenetic/Netcraze отвечают на них «invalid I1 value», а серверу они не нужны (их отправляет только клиент). MikroTik AmneziaWG не поддерживает.

В конфиге адрес сервера — ваш домен DuckDNS (если настроен), поэтому смена IP роутер не затрагивает.

Если открыть ссылку-подписку в браузере, будет страница со статусом, QR-кодом и кнопкой «Копировать».

## Обновления

**⬆️ Обновления** в боте показывает текущие и последние версии:

- **Xray / Hysteria2** — кнопка «⬆️ …» скачивает релиз с GitHub, проверяет, что он запускается и принимает конфиг, и перезапускает ядро. Если что-то не так — «↩️ Откатить».
- **Бот** — до нажатия видно, что принесёт новая версия; кнопка «⬆️ Обновить бота»: сервер скачивает новую версию и готовый образ и перезапускается (VPN пропадает на 10–30 секунд). После этого бот пришлёт «Бот обновлён» и список изменений. Сам сервер не обновляется — только по кнопке или команде, если не включено автообновление.
- **🌙 Автообновление ночью** (кнопка в **⬆️ Обновления**, по умолчанию выключено): в 3–4 ночи по Москве бот сам ставит новую версию, если она вышла на GitHub не меньше 6 часов назад. Версию, с которой вы откатились, он пропускает и ждёт следующую. Сообщение о ночном обновлении приходит без звука.
  Если ночное обновление сломало работу, бот откатится сам. Не запустился новый бот за 10 минут — сервер возвращает прежнюю версию. Бот запустился, но VPN не работает (ядро упало, Xray не принимает подключения, сервер не отвечает ниоткуда) — бот проверяет каждые 10 минут в течение полутора часов и после 4 неудачных проверок подряд (~40 минут) возвращает прежнюю версию. Пропущенная версия больше не ставится, о причине бот пишет.

- **AmneziaWG** собирается из исходников при сборке образа, поэтому обновляется вместе с ботом.

То же вручную на сервере: `./vpn.sh update`.

Образ бота собирается на GitHub (`.github/workflows/image.yml`) и скачивается готовым — обновление занимает около минуты. Если готового образа нет или он ещё собирается, сервер соберёт его сам.

## Если IP сервера заблокировали

**Сторож.** Раз в час бот проверяет через check-host.net, доступен ли сервер из российских сетей. Если доступ пропал у всех провайдеров или у части из них, бот пишет админу. Проверить вручную: **📊 Сервер → 📡 Доступность из РФ**.

**Свой адрес вместо IP (DuckDNS).** Устройства подключаются к имени `ИМЯ.duckdns.org`, а бот каждые 5 минут сообщает DuckDNS текущий IP сервера. Если хостер сменит IP, на устройствах ничего менять не нужно.
1. Войдите на [duckdns.org](https://www.duckdns.org) через Google или GitHub, придумайте имя и скопируйте **token**.
2. На сервере: `./vpn.sh ddns ИМЯ ТОКЕН`.
3. Один раз обновите устройства: подписку в Happ, адрес пира на роутере (`ИМЯ.duckdns.org:ПОРТ`), `.conf` AmneziaWG.

**Хостер выдал дополнительный IP** вместо замены (старый заблокирован, новый добавлен рядом): укажите новый явно — `./vpn.sh ddns ИМЯ ТОКЕН НОВЫЙ_IP`. Иначе бот сообщит DuckDNS основной адрес, с которого сервер выходит в интернет. Список адресов сервера: `hostname -I`.

**Максимальная маскировка** (нужен DuckDNS): `./vpn.sh stealth`. VLESS переезжает на стандартные порты 443 (Reality) и 8443 (XHTTP), в SNI указывается свой домен, совпадающий с IP. Всем, кто не является клиентом (DPI-проверки, браузеры), сервер показывает обычный сайт «Заметки» с настоящим сертификатом. В Happ после этого нажмите 🔄 у подписки, роутер и AmneziaWG не меняются. Откатить: `./vpn.sh stealth off`.

## Команды на сервере

```bash
./vpn.sh status    # состояние
./vpn.sh logs      # логи бота
./vpn.sh restart   # перезапуск (перечитывает .env)
./vpn.sh ddns ИМЯ ТОКЕН  # адрес ИМЯ.duckdns.org вместо IP
./vpn.sh stealth   # маскировка под свой сайт на 443 (off — откатить)
./vpn.sh update    # обновить бота
./vpn.sh rollback  # вернуть версию, которая была до последнего обновления
./vpn.sh cleanup   # освободить место на диске
./vpn.sh import-awg wg0|wg1 [--apply]  # перенести AmneziaWG с mercurykd/vpnbot
./vpn.sh stop      # остановить
./vpn.sh doctor    # вся диагностика одним выводом (без секретов)
```

Все данные (база пользователей, ключи, сертификаты, обновлённые ядра) лежат в `data/`. Чтобы переехать на другой сервер — установите бота там и отправьте ему файл бэкапа.

## Если не работает

- **Бот молчит** — `./vpn.sh logs`: проверьте `BOT_TOKEN` и `ADMIN_IDS` в `.env`. Бот отвечает только админам из `ADMIN_IDS`.
- **Не подключается «Reality», а «XHTTP» работает** — частая картина на мобильном интернете: оператор распознаёт длинное соединение и режет его. На сервере это не исправить; используйте **XHTTP** — это та же маскировка Reality, но трафик идёт короткими запросами, как у обычного сайта. Чужой популярный SNI (`microsoft.com`, `yandex.ru`) не используйте: за него блокируют — по умолчанию ссылки без SNI, а после `./vpn.sh stealth` в SNI ваш домен. Обновите подписку в приложении после любых изменений.
- **Hysteria2 медленная или не работает** — у некоторых провайдеров режется UDP/QUIC: включите **Обфускация** в настройках или пользуйтесь XHTTP или Reality.
- **AmneziaWG: рукопожатие есть, интернета нет** — проверьте `cat /proc/sys/net/ipv4/ip_forward` (должно быть `1`, `./vpn.sh update` выставит) и что у хостера открыт `51820/udp`.
- **AmneziaWG не подключается вообще** — после смены ключей (**🔑 Новые ключи AWG**) старые `.conf` недействительны, выдайте заново.
- **Ядро упало** — **📜 Логи** в боте покажут причину; **📊 Сервер → ♻️ Перезапуск ядер**.
- **В ключах неверный IP** — **⚙️ Настройки → 📍 Адрес сервера** (или `SERVER_HOST` в `.env`).

## Перенос с mercurykd/vpnbot

Если на сервере уже стоит [mercurykd/vpnbot](https://github.com/mercurykd/vpnbot), можно перейти на том же сервере, ничего не теряя:
1. **Бэкап:** `tar czf /root/vpnbot-backup-$(date +%F).tgz -C /root vpnbot`
2. **Остановить mercurykd/vpnbot** (он занимает 443): `cd /root/vpnbot && make d` (или `docker compose down`).
3. **Установить VPN Bot Lite** — шаг 1 из «Установки». Токен бота можно оставить прежним.
4. **Перенести AmneziaWG**, чтобы роутеры и телефоны со старыми конфигами продолжили работать без изменений:
   ```bash
   ./vpn.sh import-awg wg0            # проверка: что будет перенесено (wg0 — порт 51820, wg1 — 51821)
   ./vpn.sh import-awg wg0 --apply    # перенос: ключ сервера, маскировка, клиенты; порт и подсеть пропишутся сами
   ```
5. **Шаги 2–3** (домен и маскировка).
6. **VLESS-пользователей** нужно добавить заново и раздать им новые ссылки-подписки: ключи другие.
7. На роутерах можно оставить старый адрес — работать будет. Но лучше один раз поменять «Адрес и порт пира» на `ИМЯ.duckdns.org:ПОРТ`, тогда смена IP их не затронет.

Откат: `./vpn.sh stop`, затем `cd /root/vpnbot && make u`.
