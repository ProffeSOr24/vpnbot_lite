# VPN Bot Lite

Свой VPN-сервер, которым управляют из Telegram-бота. Сделан под блокировки в России: снаружи сервер выглядит как обычный сайт, а при смене IP устройства перенастраивать не нужно.

- **Протоколы:** VLESS XHTTP + Reality (телефоны и ПК, приложение Happ) и AmneziaWG 2.0 (роутеры и приложения).
- **Маскировка:** VPN спрятан за обычным сайтом на вашем домене с настоящим сертификатом.
- **Сторож:** раз в час проверяет доступность из России и пишет, что именно блокируют.
- **Просто:** один контейнер + Caddy, 1 ГБ RAM, обновления кнопкой в боте.

Что нового — [CHANGELOG.md](CHANGELOG.md).

## Установка

Нужны VPS за рубежом (Ubuntu 22.04/24.04 или Debian 12), токен бота от [@BotFather](https://t.me/BotFather), ваш ID из [@userinfobot](https://t.me/userinfobot) и бесплатный домен на [duckdns.org](https://www.duckdns.org) (имя + token).

```bash
apt-get update && apt-get install -y git
git clone https://github.com/ProffeSOr24/vpnbot_lite.git /opt/vpnbot-lite
cd /opt/vpnbot-lite
./vpn.sh install <ТОКЕН_БОТА> <ВАШ_ID>    # Docker, настройки ядра, бот
./vpn.sh ddns <ИМЯ> <ТОКЕН_DUCKDNS>       # свой адрес ИМЯ.duckdns.org и https
./vpn.sh stealth                          # VPN за сайтом на 443/8443
```

Проверка: `https://ИМЯ.duckdns.org` в браузере открывает сайт «Заметки о Linux».

## Пользователи

`/menu` → **👥 Пользователи** → **➕ Добавить** → `ivan` или `ivan 30 100` (30 дней, 100 ГБ). В карточке:

- **🔗 Ключи и QR** — подписка для Happ (на странице подписки есть кнопка «Добавить в Happ»);
- **📡 AWG приложение** — `.conf` для AmneziaWG на телефоне/ПК;
- **📶 AWG роутер** — `.conf` для Keenetic/Netcraze (Интернет → Другие подключения → WireGuard → Загрузить из файла) или OpenWrt.

## Если IP заблокировали

Бот пишет, что именно блокируют: IP целиком, порт, DNS или имя (SNI). Если IP:

1. Закажите у хостера **дополнительный IP**, старый не удаляйте — через него сервер будет выходить в интернет.
2. В `.env` добавьте `DDNS_IP=НОВЫЙ_IP`, затем `sudo ./vpn.sh restart`.

Бот переведёт DuckDNS на новый адрес, устройства переподключатся сами. Сайты будут видеть старый IP, а подключаться люди будут к новому, который нигде не светится.

## Только AmneziaWG

`VLESS=0` в `.env`, затем `sudo ./vpn.sh restart`: Xray не запускается, из бота пропадает всё про VLESS, сайт остаётся на 443. Вернуть — удалить строку и снова `restart`; людям достаточно обновить подписку.

## Порты

| Порт | Что |
|---|---|
| 443/tcp | сайт (VLESS Reality — если включён в настройках) |
| 8443/tcp | VLESS XHTTP |
| 2443/tcp | подписки (https) |
| 80/tcp | сертификат Let's Encrypt |
| 51820/udp | AmneziaWG |

## Команды

```bash
./vpn.sh status | logs | restart | stop
./vpn.sh update      # обновить (то же — кнопка в боте; можно включить ночное автообновление)
./vpn.sh rollback    # вернуть предыдущую версию
./vpn.sh doctor      # диагностика без секретов
./vpn.sh cleanup     # освободить диск
./vpn.sh import-awg wg0 [--apply]   # перенести AmneziaWG с mercurykd/vpnbot
```

Свои настройки — только в `.env` (обновления его не трогают), после правки — `./vpn.sh restart`. Файлы репозитория руками не меняйте: иначе обновление не пройдёт.

**Бэкап** базы бот присылает каждую ночь, если что-то поменялось. Восстановить — переслать файл боту. Переезд на новый сервер: установить бота с тем же токеном, переслать ему бэкап, повторить `ddns` и `stealth`.

## Если не работает

- **Бот молчит** — `./vpn.sh logs`, проверьте `BOT_TOKEN` и `ADMIN_IDS` в `.env`.
- **Happ не подключается** — обновите подписку (потянуть список вниз), попробуйте Wi-Fi ↔ мобильный.
- **AmneziaWG: рукопожатие есть, интернета нет** — у хостера должен быть открыт UDP-порт AWG.
- **Ядро упало** — **📜 Логи** в боте, **📊 Сервер → ♻️ Перезапуск ядер**.
- Прислать разработчику — вывод `./vpn.sh doctor`.
