Мониторинг для одного сервера

21 сентября 2026

Для одной машины не нужен целый стек наблюдаемости. Хватает трёх вещей: следить за диском, памятью и тем, что нужные сервисы живы.

Минимальный набор

  • Диск — предупреждение при заполнении на 80%, автоочистка старых логов и образов Docker.
  • Память — swap на 1–2 ГБ спасает от внезапного OOM на маленьких VPS.
  • Сервисы — systemctl is-active по расписанию и сообщение в мессенджер, если что-то упало.
df -h /           # сколько места
free -h           # память и swap
journalctl -p err -b   # ошибки с последней загрузки

Главное — чтобы оповещения были редкими и по делу. Алерт, который приходит каждый час, через неделю перестают читать.
