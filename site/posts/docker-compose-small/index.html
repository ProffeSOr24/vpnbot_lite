Docker Compose на маленьком VPS

14 июля 2026

На сервере с 1 ГБ памяти Compose удобнее, чем установка всего прямо в систему: каждый сервис изолирован, а обновление — это docker compose pull && docker compose up -d.

Что настроить сразу

  • Ротация логов. Без неё json-логи контейнеров рано или поздно съедят диск.
  • Перезапуск. restart: unless-stopped поднимет сервис после перезагрузки.
  • Данные — в volume. Всё, что не в volume, исчезнет при пересоздании контейнера.
services:
  app:
    image: example/app:1.4
    restart: unless-stopped
    volumes:
      - ./data:/data
    logging:
      driver: json-file
      options: { max-size: "10m", max-file: "3" }

И не забывайте чистить старые образы: docker image prune -f.
