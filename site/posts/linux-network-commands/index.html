Пять команд для диагностики сети

9 февраля 2026

Когда «ничего не работает», почти всегда хватает пяти команд, чтобы понять, на каком уровне проблема.

ip a                 # какие адреса у интерфейсов
ip route             # куда уходят пакеты по умолчанию
ss -tulpn            # какие программы слушают какие порты
dig example.org      # работает ли DNS
curl -v https://example.org   # TLS и ответ сервера

Идти лучше снизу вверх: есть ли адрес, есть ли маршрут, отвечает ли DNS, открывается ли порт, что отвечает приложение. Так проблема находится за минуты, а не за вечер.

Если команды dig нет, она ставится пакетом dnsutils.
