SSH только по ключам

30 августа 2026

Первое, что стоит сделать на свежем сервере, — отключить вход под root и по паролю. В логах любого сервера с открытым 22-м портом через час появятся тысячи попыток подбора.

По шагам

  1. Создать пользователя и дать ему sudo: adduser admin && usermod -aG sudo admin.
  2. Положить свой публичный ключ в ~admin/.ssh/authorized_keys.
  3. Проверить вход по ключу в новом окне, не закрывая текущее.
  4. Только после этого выключить пароли.
# /etc/ssh/sshd_config.d/00-hardening.conf
PermitRootLogin no
PasswordAuthentication no
KbdInteractiveAuthentication no
sshd -t && systemctl restart ssh

sshd -t проверяет конфигурацию до перезапуска — с опечаткой в файле сервис просто не стартует, и доступ пропадёт.
