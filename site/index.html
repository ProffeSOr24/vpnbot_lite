  • SSH только по ключам30 августа 2026

    Первое, что стоит сделать на свежем сервере, — отключить вход под root и по паролю. В логах любого сервера с открытым 22-м портом через час появятся тысячи попыток подбора.

  • Docker Compose на маленьком VPS14 июля 2026

    На сервере с 1 ГБ памяти Compose удобнее, чем установка всего прямо в систему: каждый сервис изолирован, а обновление — это docker compose pull && docker compose up -d.

  • DNS для домашнего сервера2 июня 2026

    У домашнего провайдера IP-адрес часто меняется. Чтобы не перенастраивать устройства каждый раз, удобно завести динамический DNS: имя, которое само следует за адресом.
